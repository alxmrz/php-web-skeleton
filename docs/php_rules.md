# Правила написания PHP-кода

Общие правила — в `docs/general_rules.md`; здесь только специфика PHP.

## Строгий режим

- В каждом PHP-файле первым оператором после `<?php` — `declare(strict_types=1);`.
- Не полагайся на неявные приведения типов: параметры и возвращаемые значения описывай
  явными типами.

## Типы

- Не используй `mixed`.
- Там, где без `mixed` не обойтись (например, произвольные данные из JSON или БД),
  сужай и документируй тип PHPDoc-аннотациями с дженериками:
  `array<string, mixed>`, `list<int>`, `array<int, Order>` и т. п.
- Для необязательных значений предпочитай явные nullable-типы (`?array`) вместо `mixed`.

## Модификаторы

- Используй `readonly` для свойств и зависимостей, которые не меняются после создания
  объекта (в том числе в promoted-свойствах конструктора).
- Используй `final` для классов, которые не предназначены для наследования, и не открывай
  наследование без необходимости.
